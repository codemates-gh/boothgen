# Genie Standard poses

Pose ideas for the Genie pose library (P11): guests choose Solo (Her / Him / All) or Group (For two / For groups)
and see these as white silhouettes on a dark card, before Start and one per shot during the countdown. They seed
BoothGen's site-wide **Standard** pose library (Super Admin → Poses → Import starter poses); operators add their
own ("My poses").

- 48 poses: `her-01…12`, `him-01…12`, `two-01…12` (two people), `groups-01…12` (4–6 people).
- `png/` transparent PNGs, 1024×1024, figure in white; `thumb/` the same at 360 px; `catalog.json` ids, names,
  categories, sizes and SHA-256 (checked on import).
- Copied unchanged from the Genie repo's `assets/poses` (made and checked there; to remake the set, see the README
  there, then copy `png/`, `thumb/` and `catalog.json` here again).

# Template text fonts

Regular (400) Latin files of Google Fonts families, via Fontsource. Each is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org): free to use, embed and print commercially. BoothGen hosts them so the designer, the client
portal and the server draw identical template text (src/lib/templates/textLayer.ts).

playfair (Playfair Display), cormorant (Cormorant Garamond), cinzel (Cinzel), montserrat (Montserrat), raleway (Raleway),
josefin (Josefin Sans), lato (Lato), bebas (Bebas Neue), great-vibes (Great Vibes), dancing (Dancing Script),
pacifico (Pacifico), sacramento (Sacramento).
